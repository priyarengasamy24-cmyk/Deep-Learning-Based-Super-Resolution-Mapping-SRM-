🛰️ GeoSR-X | AI-Powered Satellite Image Enhancement

**Sharper Earth Insights Through Deep Learning.**

GeoSR-X is a deep learning-based satellite imagery super-resolution project that aims to transform native 10 m Sentinel-2 imagery into enhanced 2.5 m spatial representations using a hybrid **CNN + Swin Transformer** architecture.

 Key Features
-  Sentinel-2 multispectral GeoTIFF support
-  Blue, Green, Red & NIR band selection
-  AI-based super-resolution workflow
-  Image quality evaluation (PSNR, SSIM, SAM, ERGAS)
-  Geospatial visualization
-  Original vs enhanced image comparison

 Technology
Base44 • Deep Learning • CNN • Swin Transformer • Sentinel-2 • GeoTIFF
